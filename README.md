# 영상의학과 근무·근태 관리 프로그램 MVP

병원 영상의학과 조기출근 OT를 하루 단위로 기록하고, MRI 담당 1명과 X-ray 담당 1명을 공정하게 추천하는 로컬 실행 프로그램입니다. 화요일/금요일 야간근무 담당자도 날짜별로 직접 입력할 수 있습니다.
개인별 휴가/근태/시간 기록은 외부 연동을 위해 `date, name, ot, nightOt, holidayOt, flexOt, off, note` 필드로 별도 저장합니다.

서버 설치 없이 브라우저에서 바로 열어 사용합니다. 데이터는 현재 브라우저의 로컬 저장소(LocalStorage)에 저장되며, JSON 백업/복원으로 파일 보관이 가능합니다.

## 폴더 구조

```text
OT_generator/
  README.md
  public/
    index.html          # 더블클릭해서 실행하는 화면
    styles.css          # 화면 디자인
    app.js              # 저장, 추천 알고리즘, 통계, CSV/JSON 내보내기
```

## 실행 방법

1. `실행하기.html` 파일을 더블클릭합니다.
2. 브라우저에서 프로그램이 열리면 바로 사용합니다.

직접 열고 싶다면 `public/index.html`을 더블클릭해도 됩니다.

별도 설치, 서버 실행, npm 명령이 필요 없습니다.

## 데이터 저장 방식

- 직원 정보와 날짜별 기록은 브라우저 LocalStorage에 자동 저장됩니다.
- 같은 PC와 같은 브라우저에서 다시 열면 기존 데이터가 유지됩니다.
- 브라우저 캐시/사이트 데이터를 삭제하면 저장 데이터도 삭제될 수 있으므로 `JSON 백업` 버튼으로 정기 백업을 권장합니다.
- 다른 PC나 브라우저로 옮길 때는 `JSON 백업` 후 새 환경에서 `JSON 복원`을 사용합니다.

## 사용 방법

1. 직원 관리에서 실제 직원 이름과 MRI 가능 여부를 등록합니다. X-ray는 기본 가능 업무로 처리됩니다.
2. 메인 화면에서 날짜를 선택합니다.
3. 조기출근을 입력하려면 `조출 입력`을 누르고 `선택 날짜 추천 받기` 또는 `내일 추천 받기`를 누릅니다.
4. 추천 사유를 확인합니다.
5. 필요하면 조출 MRI 담당자 또는 X-ray 담당자를 수동 변경합니다. 직원별 조출 시간을 같이 남기려면 담당자 선택 아래의 시간 입력칸에 입력합니다.
6. 화요일/금요일 야간근무가 있으면 `야간 입력`을 누르고 야간 MRI 담당자와 야간 X-ray 담당자를 직접 선택합니다. 직원별 야간 시간을 같이 남기려면 담당자 선택 아래의 시간 입력칸에 입력합니다.
7. 개인 근태를 입력하려면 `근태 입력`을 누르고 직원별 OT 한 시간, OT 사용 시간, nightOt, holidayOt, flexOt, off, note를 입력합니다.
   예: 오전 조출 +1시간과 OT 사용 -4시간이 같은 날이면 OT 한 시간에는 `1`, OT 사용 시간에는 `-4` 또는 `4`를 입력합니다. note는 `OT(1) + OT사용 반차(-4)`로 자동 입력되고, 외부 연동 CSV의 ot는 자동으로 `-3`이 됩니다. OT 한 시간만 있으면 note에는 자동 기록하지 않습니다. flexOt가 음수이면 `탄력 사용(-2)`도 note에 자동 입력됩니다.
8. 토요일 OFF자는 `근태 입력` 안의 `토요일 OFF 직원` 체크 목록에서 여러 명 선택해 저장합니다. 선택한 직원은 off가 `토요일OFF`가 되고, 나머지 재직 직원은 holidayOt가 4로 자동 입력됩니다.
9. `이 날짜 기록 확정`을 눌러 조출/야간 배정 기록을 저장합니다.
10. 조기출근 담당자를 비워 두면 조기출근 없음으로 자동 저장됩니다. 야간근무만 입력해도 저장할 수 있습니다.
11. 오른쪽 월별 현황에서 직원별 총 OT, MRI, X-ray 횟수와 공정성 상태를 확인합니다.
12. `CSV 내보내기`로 조출/야간 배정 기록을 엑셀에서 열 수 있는 CSV 파일로 저장합니다.
13. `근태 CSV 내보내기`로 개인 근태 기록을 외부 프로그램에서 가져갈 수 있는 CSV 파일로 저장합니다.
14. `JSON 백업`으로 전체 데이터를 백업하고, 필요 시 `JSON 복원`으로 되돌립니다.

## 데이터 구조

브라우저 내부에는 아래 구조로 저장됩니다.

- `employees`: 직원 정보, MRI 가능 여부, OT 대상 여부, 야간 대상 여부
- `records`: 날짜별 조기출근 여부, OT MRI 담당자, OT X-ray 담당자, 야간 MRI 담당자, 야간 X-ray 담당자, 메모
- `attendanceRecords`: 개인별 근태 기록. 필드는 `date`, `name`, `ot`, `nightOt`, `holidayOt`, `flexOt`, `off`, `note`입니다.
- `exceptions`: 향후 근태/제외 사유 확장을 위한 자리
- `settings`: 운영 요일, 기본 OT 요일, 공정성 기준 등 설정값

## 추천 알고리즘

추천은 랜덤이 아니라 점수 기반입니다.

- MRI 담당자는 MRI 가능 직원 중에서만 고릅니다.
- X-ray 담당자는 기본 가능 업무로 보고 OT 대상 직원 중에서 고릅니다.
- MRI 담당자와 X-ray 담당자는 같은 사람이 될 수 없습니다.
- 이번 달 총 OT 횟수가 적을수록 우선합니다.
- 해당 업무 담당 횟수가 적을수록 우선합니다.
- 선택 날짜 이전의 가장 최근 조기출근일에 근무한 직원은 큰 점수를 더해 우선순위를 낮춥니다.
- 마지막 OT 이후 오래 지난 직원은 약간 우선합니다.
- MRI 가능자가 부족하면 예외적으로 직전 조기출근일 근무자를 추천할 수 있고, 경고 문구를 표시합니다.

공정성은 월별 최소/최대 횟수 차이로 계산합니다.

- 차이 0~1회: 양호
- 차이 2회: 주의
- 차이 3회 이상: 경고

공정성 상태는 전체 OT 횟수 기준으로 보여줍니다. MRI와 X-ray 담당 횟수는 직원별 현황 표에서 참고용으로 확인합니다.

## 샘플 데이터

첫 실행 시 `김민수`, `이서연`, `박지훈`, `최유진` 샘플 직원이 자동 생성됩니다. 실제 운영 전 직원 관리 화면에서 이름과 가능 업무를 수정하면 됩니다.

## 현재 MVP 범위

- 직원 등록/수정/삭제
- MRI 가능 여부, OT 대상 여부, 야간 대상 여부 설정
- 날짜 선택
- 조기출근 있음/없음 기록
- MRI 1명, X-ray 1명 추천
- 추천 사유 표시
- 수동 담당자 변경 후 확정
- 화요일/금요일 야간근무 MRI 1명, X-ray 1명 직접 입력
- 개인별 근태/휴가/시간 기록 입력 및 근태 CSV 내보내기
- 토요일 OFF 직원 여러 명 지정 및 나머지 재직 직원 holidayOt 4시간 자동 입력
- 직원별 입사일/퇴사일과 MRI 가능 시작일, OT 대상 시작일, 야간 대상 시작일 기준으로 해당 날짜 가능한 직원만 추천/선택/휴일근무 계산에 포함
- 직원 목록 순서 변경 및 최종 선택된 두 명 중 MRI 담당자 결정에 순서 반영
- 월별 총 OT/MRI/X-ray 횟수 표시
- 브라우저 로컬 저장
- CSV 내보내기
- JSON 백업/복원

## 향후 확장 아이디어

- 날짜별 연차, 반차, 당직, 교육, 출장 등 제외 사유 관리 화면 추가
- 설정 화면에서 운영 요일과 공정성 기준 직접 수정
- Electron으로 포장해 더블클릭 실행 파일 제공
- 월별 통계 Excel 파일 생성
- 직원별 장기 미배정 경고와 MRI 편중 상세 리포트
